Project

Expense Tracker

A Python app that saves and summarises spending.

Why I built it

I started it as a university student to help me save money whilst studying.

What it does

The app asks the user what they bought, its category and cost. It also remembers the date, so the user can see monthly breakdowns.

What I learned / what I'm proud of

The code taught me the basics of Python programming, and helped me learn to prompt Claude Code to develop the idea further, towards a mobile-friendly web app.
